# LLM Benchmark 前端设计规范

## 产品定位

- **对象**：在内网中验证 OpenAI 兼容模型服务的开发、运维与测试人员。
- **单一核心任务**：在不误发高风险负载的前提下，快速配置、运行、观察并复查一次性能实验。
- **设计隐喻**：精密测试台，而非通用管理后台。界面应像一套可校准、可复现、可停止的测量仪器。

## 设计令牌

### 颜色

| 名称 | 色值 | 用途 |
|---|---:|---|
| 深海台面 | `#10262F` | 主导航、登录背景、强对比区域 |
| 石墨刻度 | `#263B43` | 主文字、边框、数据刻度 |
| 雾灰工作面 | `#EEF3F3` | 页面背景 |
| 稳态青绿 | `#008E91` | 正常运行、主操作、有效数据 |
| 风险琥珀 | `#D58A24` | 风险确认、等待、降级 |
| 停止红 | `#C54B4B` | 停止、失败、不可逆动作 |

不使用大面积渐变。颜色承担状态语义，不作为无意义装饰。

### 字体

完全使用操作系统字体，不加载 CDN 或字体文件：

- 标题/导航：`Bahnschrift`, `Segoe UI Semibold`, `Microsoft YaHei`, sans-serif。
- 正文：`Segoe UI`, `Microsoft YaHei`, Arial, sans-serif。
- 数据/刻度：`Consolas`, `Cascadia Mono`, `Courier New`, monospace。

数字默认启用等宽数字；关键性能数据使用数据字体，避免刷新时宽度跳动。

### 间距与形状

- 基础间距：4px；常用间距：8 / 12 / 16 / 24 / 32px。
- 面板圆角：6px；按钮圆角：4px。避免夸张胶囊按钮。
- 阴影只用于浮层；普通面板依靠 1px 边框和色面分层。
- 键盘焦点：2px 青绿色外框，偏移 2px。

## 布局

1366×768 基准布局：

```text
┌──────────── 220px 设备导航 ────────────┬────────────── 工作区 ──────────────┐
│ 标识 / 服务状态                       │ 页面标题 / 当前任务 / 快捷操作       │
│ 新建测试                              ├─────────────────────────────────────┤
│ 运行监控                              │ 负载轨迹标尺（贯穿页面）             │
│ 测试记录                              ├──────────────┬──────────────────────┤
│ 测试资源                              │ 配置/数据区   │ 预检/指标/状态区       │
│ 设置诊断                              │              │                      │
└───────────────────────────────────────┴──────────────┴──────────────────────┘
```

窄屏下导航变成顶部横向滚动条，双栏内容改为单栏；不隐藏关键停止按钮、状态和错误信息。

## 标志性交互：负载轨迹标尺

标尺同时表达：

- warmup / load / cooldown 阶段；
- 固定并发、阶梯并发、恒定 QPS 与稳定性时长；
- 已完成、当前进度、尚未执行；
- 阈值违规与安全停止点。

标尺使用原生 CSS/SVG，不依赖图表库；鼠标悬停和键盘聚焦均显示阶段、并发、QPS、完成量。实时更新只改变填充宽度与当前指针，不进行无意义循环动画。

## 动效与兼容性

- 仅使用 opacity/transform/width 的短过渡。
- `prefers-reduced-motion: reduce` 下关闭所有非必要过渡与动画。
- 构建 target：Chrome 80+、Firefox 78+；验收环境为 Windows 7 Chrome 109 与 Firefox 115 ESR。
- 不使用 IE 专用代码，不依赖 CSS `:has()`、容器查询、WebGPU 等新特性。
- EventSource 失败后退化到 2 秒状态轮询；浏览器关闭不影响服务端任务。

## 自我审查

最初方案包含常见的“顶部四张 KPI 卡片 + 左侧导航”，过于像通用监控模板。调整后：

1. 负载轨迹标尺成为页面首要结构，而非装饰图表；
2. 指标采用实验仪器式读数带，而不是浮动卡片阵列；
3. 所有导航和文案围绕“配置—预检—运行—复查”的真实实验流程；
4. 视觉风险集中在标尺这一处，其余组件保持低噪声和高密度。
